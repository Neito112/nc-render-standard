Prompt templates dùng cho CUDA render tool. Mỗi template gồm positive + negative.

## Quick append patterns

Kết hợp nhanh với prompt baseline:

```
# Đổ bóng mạnh
+ "dramatic shadows, high contrast, volumetric lighting"

# Phong cách warm
+ "warm tone, golden hour, cozy atmosphere"

# Phong cách cool
+ "cool ambient, blue tone, minimal"

# Nâng cao detail
+ "sharp focus, highly detailed, unreal engine 5 quality, ray tracing"

# Giảm clutter
+ "minimalist, clean, uncluttered, empty space"
```
